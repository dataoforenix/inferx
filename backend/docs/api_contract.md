# Sanna'ha API: frontend contract

Everything the frontend needs, on one page. Real response bodies for every case are in
[`examples/`](examples/) (generated by the app itself), and the machine-readable schema is
[`openapi.json`](openapi.json). With the server running, interactive docs are at `/docs`.

- **Base URL (local):** `http://localhost:8000`
- **Format:** JSON everywhere, except `POST /api/analyze`, which takes `multipart/form-data`.
- **Request IDs:** every response carries an `X-Request-ID` header (also `request_id` in the body).
  Show it in error toasts; it's what the backend logs.

## Endpoints

| Method | Path | Body | Returns | Calls the AI? |
|---|---|---|---|---|
| GET | `/api/health` | — | `HealthResponse` | no |
| GET | `/api/categories` | — | `CategoriesResponse` | no |
| POST | `/api/analyze` | multipart: `image?`, `text?`, `language` | `AnalyzeResponse` | yes |
| POST | `/api/analyze/confirm` | JSON `ConfirmRequest` | `AnalyzeResponse` | yes (explanation only) |
| POST | `/api/whatif` | JSON `WhatIfRequest` | `WhatIfResponse` | **no** (instant) |

## `POST /api/analyze`

| Field | Type | Rules |
|---|---|---|
| `image` | file | optional; JPEG, PNG or WebP; max 8 MB |
| `text` | string | optional; max 1000 characters; Arabic or English |
| `language` | `"en"` \| `"ar"` | language of the explanation; default `"en"` |

At least one of `image` / `text` is required.

```js
const form = new FormData();
if (file) form.append("image", file);
if (text) form.append("text", text);
form.append("language", lang); // "ar" | "en"
const res = await fetch(`${API}/api/analyze`, { method: "POST", body: form }); // don't set Content-Type yourself
```

> **Content-Length is required.** The backend rejects uploads without a `Content-Length` header
> (`411 length_required`), so an upload can never be spooled to disk. Browsers send it
> automatically for `FormData`. **A dev proxy (e.g. Vite `server.proxy`) must forward the body
> as-is and not switch to chunked transfer encoding.** If you get `411`, call the backend directly
> (CORS is enabled for the dev origins below) or fix the proxy so it forwards `Content-Length`.

### Response: `AnalyzeResponse`

Branch on `status`:

| `status` | What to show | Present fields |
|---|---|---|
| `complete` | The full result | `product`, `report`, `explanation`, `explanation_source` |
| `needs_confirmation` | "Which of these is your product?" picker built from `candidates` | `product`, `candidates` (`report` and `explanation` are `null`) |
| `unsupported` | "This product isn't covered yet" + `GET /api/categories` list | `product` (with `category_id: null`), maybe `candidates` |
| `market_preview` | "Preliminary market scan" card (see below) | `product` (with `category_id: null` and `hs6_guess`), `report`, `explanation`, `explanation_source: "template"` |

Always present: `request_id`, `status`, `language`, `source`, `needs_confirmation`, `candidates`,
`warnings` (show them as small notices), `timings_ms`.

Examples: [`analyze_complete_en.json`](examples/analyze_complete_en.json),
[`analyze_complete_ar.json`](examples/analyze_complete_ar.json),
[`analyze_needs_confirmation.json`](examples/analyze_needs_confirmation.json),
[`analyze_unsupported.json`](examples/analyze_unsupported.json),
[`analyze_market_preview.json`](examples/analyze_market_preview.json).

### Handling `market_preview`

Returned (live mode only, never in demo mode) when the product is physical but fits none of the categories, the
AI suggested a 6-digit HS code, and UN Comtrade returned Jordan's imports for it. Everything except the imports is
unknown, so:

- `report.flags` contains `"market_preview_only"`; `report.verdict` is always `MAYBE` with
  `verdict_forced_maybe: true`, and cost / feasibility / competition scores are `null` (listed in `missing_fields`).
  **Don't show `report.score` as a feasibility score**: it's the market component alone. Show the market card
  (`imports_usd`, `market.*`, `import_weight_kg_2024`) under a "Preliminary market scan" title.
- Show `product.hs6_guess` (= `report.hs6`) with a note that the code was guessed by the AI and should be checked;
  the figures belong to that code. Years Comtrade couldn't return in time are `null` in `imports_usd` (the public
  API is rate-limited; 2024 is always present, 2020 almost always).
- `explanation` is a fixed template (no AI call): what was found, and which data (cost, machinery, competition) is
  needed to decide.
- `report.category_id` is `"market_preview"`, not a real category: `/api/analyze/confirm` and `/api/whatif` with it
  return `404 unknown_category`.
- The call to UN Comtrade adds up to ~10 s (`timings_ms.market_data`). If it fails or has no 2024 data, you get the
  normal `unsupported` response with an extra warning.

### Handling `needs_confirmation`

1. Show `product.name_en`/`name_ar` and the `candidates` (each has `category_id`, `name_en`,
   `name_ar`, `confidence` 0–1). The first candidate is the AI's best guess.
2. When the user picks one, call `POST /api/analyze/confirm`:

```json
{
  "category_id": "plastic_tableware",
  "language": "ar",
  "product": { "name_en": "Plastic folding chair", "name_ar": "كرسي بلاستيك قابل للطي", "description": "A folding chair made mostly of moulded plastic." }
}
```

`product` is optional (pass the one from the first response so the explanation uses the user's
product name; each field max 200/200/600 chars). The response is an `AnalyzeResponse` with
`status: "complete"`. Unknown `category_id` returns `404 unknown_category`. Example:
[`confirm_complete.json`](examples/confirm_complete.json) (tomato_paste: cost gate + capital flag),
[`confirm_complete_ar.json`](examples/confirm_complete_ar.json),
[`confirm_complete_all_fields.json`](examples/confirm_complete_all_fields.json) (frozen_fries: every optional field).

## The `report` object (render the cards from this; no second lookup needed)

All numbers are calculated in Python from the data file; the AI never produces them.

| Card | Fields |
|---|---|
| Score + verdict | `score` (0–10, one decimal, may be `null` if no data), `verdict` (`MANUFACTURE` \| `MAYBE` \| `DONT`), `verdict_forced_maybe` (true = data too incomplete to trust the score), `verdict_capped_by` (`"cost_gate"` = the verdict was limited because producing locally costs more than importing: margin < 0 → at most MAYBE/5.9, margin < −0.25 → DONT/3.9; else `null`; show a badge), `data_completeness` (0–1) |
| Market | `market.score`, `market.latest_import_usd`, `market.cagr` (fraction: 0.075 = 7.5%/year), `trend_label` (`growing` \| `stable` \| `declining` \| `null`), `imports_usd` (`{"2020": …, "2024": …}`, values may be `null`) |
| Cost | `cost.score`, `cost.import_price_per_kg_usd` (CIF: freight and insurance included), `cost.customs_pct` (fraction), `cost.landed_cost_per_kg_usd` (= CIF price × (1 + customs)), `cost.local_cost_per_kg_est_usd`, `cost.margin` (fraction; negative = imports are cheaper). `cost.shipping_pct` is information only (don't add it to any cost). |
| Cost build-up | `cost.raw_material_price_usd_per_kg`, `cost.material_kg_per_kg_product`, `cost.conversion_cost_per_kg_usd` (local cost ≈ raw material × ratio + conversion; any may be `null`) |
| Manufacturing | `feasibility.score`, the three 0–5 ratings, `machinery` (list), `raw_materials` (list) |
| Equipment cost | `capex_usd_range` (`{min, max}` in **USD**; `null` if unknown): **equipment only: supplier listing prices ex-works, excluding shipping, customs, installation, moulds and buildings.** Always show that caption. `machine_source` (text: where the prices come from). `machine_cost_range_jod` is the older JOD version of the same range (prefer `capex_usd_range`). |
| Break-even | `break_even` (`null` unless `capex_usd_range` has min and max, `import_weight_kg_2024` exists and the landed import cost is above the local cost): `capex_mid_usd` (= (min+max)/2), `unit_saving_usd_per_kg` (= landed − local), `break_even_tons` (= capex_mid / unit_saving, in tonnes), `share_of_2024_imports` (fraction of `import_weight_kg_2024`). Always show the caption **"indicative: equipment only, excludes buildings and working capital, assumes selling at import-parity price"**. It follows `/api/whatif` overrides (use `scenario.break_even`). `import_weight_kg_2024` (kg) is also at the top level of the report. |
| Competition | `competition.score`, `competition.local_factories`, `competition.factories_saturation`, `competition_note` |
| Risks | `risk_notes` (text, may be empty) |
| Sources | `sources` (list of URLs: trade data, tariff, then equipment listings), `source_notes` (long text, ~1000 chars: show collapsed) |
| Data quality | `is_placeholder_data`, `estimated_fields`, `missing_fields`, `notes` |
| Flags | `flags`: list of `"high_capital_requirement"` (equipment `capex_usd_range.max` ≥ 250,000 USD; show it as a warning chip, it never changes the score) and `"market_preview_only"` (only on `market_preview` responses). |

Component `score` values are `null` when the data for that component is missing: show "no data",
not 0. `weights` gives the share of each component (market 0.35, cost 0.30, feasibility 0.20,
competition 0.15).

### Data-quality badges

- **`is_placeholder_data: true`** means the category's figures are illustrative placeholders, not real
  statistics. Show a clear banner on the result ("Sample data, not real statistics"). The installed data
  has no placeholders (all 6 categories are `data_status: "ESTIMATE"`), but keep the banner logic.
- **`estimated_fields`** lists CSV column names whose values are estimates. Put an **"estimate"
  badge** next to every number that comes from (or is computed from) one of them:

| Column in `estimated_fields` | Badge these report fields |
|---|---|
| `local_cost_per_kg_est_usd` | `cost.local_cost_per_kg_est_usd`, `cost.margin`, `cost.score` |
| `shipping_pct` / `customs_pct` / `import_price_per_kg_usd` | the same-named `cost.*` field, `cost.landed_cost_per_kg_usd`, `cost.margin`, `cost.score` |
| `imports_YYYY_usd` | `imports_usd["YYYY"]` (and `market.*` for 2020/2024) |
| `machinery_availability` / `raw_material_local` / `skills_availability` | the same-named `feasibility.*` rating, `feasibility.score` |
| `local_factories` / `factories_saturation` | the same-named `competition.*` field, `competition.score` |
| `machine_cost_jod_min` / `machine_cost_jod_max` | `machine_cost_range_jod` |
| `machine_cost_usd_min` / `machine_cost_usd_max` | `capex_usd_range` |
| `raw_material_price_usd_per_kg` / `material_kg_per_kg_product` / `conversion_cost_per_kg_usd` | the same-named `cost.*` field (and, since they build the local cost, treat `cost.local_cost_per_kg_est_usd` as an estimate) |

The explanation text also calls these numbers "estimates", and the template explanation adds a caveat.

## `explanation`, `explanation_source`, `source`

- `explanation`: `summary`, `reasons_for` (3), `concerns` (3), `next_steps` (3), `caveats` (0–6),
  in `explanation.language`.
- `explanation_source`
  - `"llm"`: written by the AI, and every number in it was checked against the report.
  - `"fallback"`: a deterministic template built from the same report (used when the AI is
    unavailable, or when its text quoted numbers not in the report twice in a row). Show it the same way;
    optionally a subtle "simplified explanation" hint. `warnings` says why.
  - `"template"`: a fixed template by design (only `market_preview`); no AI call was made.
- `source`
  - `"live"`: the AI analysed this request.
  - `"demo_cache"`: a prepared example (server in `DEMO_MODE`, or the AI was down and the input matched
    a prepared example). Scores are still computed live. Show a small "demo" label.

## `timings_ms`

`{normalize, market_data, score, explain, total}` in milliseconds (`market_data` = the UN Comtrade lookup of a market preview); a step that didn't run is `null`
(e.g. `needs_confirmation` has no `score`/`explain`; `/confirm` has no `normalize`). `total` covers the
whole handler including image processing. Useful for a "took 4.2 s" note and for spotting slow models.

## `POST /api/whatif` (no AI, use it for sliders)

```json
{ "category_id": "ceiling_fan", "overrides": { "customs_pct": 0.4, "local_factories": 0 } }
```

| Override | Type | Range | Meaning |
|---|---|---|---|
| `customs_pct` | number | 0–2 | fraction (0.4 = 40%) |
| `shipping_pct` | number | 0–2 | fraction; **information only**: accepted, echoed, but never changes the score (freight is already in the CIF import price); the scenario gets a note saying so |
| `local_cost_per_kg_est_usd` | number | > 0, ≤ 1,000,000 | USD/kg |
| `import_price_per_kg_usd` | number | > 0, ≤ 1,000,000 | USD/kg |
| `local_factories` | integer | 0–100,000 | count |

All optional; unknown keys → `422`. Response: `baseline` (report with the data as-is), `scenario`
(report with overrides; `scenario.overrides_applied` echoes them), `score_delta` (one decimal, may be `null`).
It's pure Python (a few ms), so calling it on every slider change (debounced ~150 ms) is fine. It does
**not** regenerate the explanation; label the scenario card "what-if". Examples: [`whatif.json`](examples/whatif.json) (tomato_paste, local cost 1.0:
crosses the cost gate, DONT → MANUFACTURE), [`whatif_shipping_info_only.json`](examples/whatif_shipping_info_only.json)
(shipping override: delta 0 plus an information-only note).

## `GET /api/categories` and `GET /api/health`

- Categories: `categories[]` with `category_id`, `name_en`, `name_ar`, `description_en`, `hs6`,
  `data_status`, `is_placeholder_data`, `missing_fields`. Today there are 6 (metal_chair, warehouse_racks,
  plastic_tableware, ceiling_fan, frozen_fries, tomato_paste), but the number can change (3–20)
  when the real data arrives: never hard-code the list.
- Health: `status` (`ok` \| `degraded`: degraded = no API key and not in demo mode, so `/analyze` will fail),
  `demo_mode`, `llm_configured`, `categories_loaded`, `data_warnings`, `demo_cache_entries`,
  `demo_cache_placeholder_entries`. Call it on app start; if `demo_mode` is true, show the demo label.

Examples: [`categories.json`](examples/categories.json), [`health.json`](examples/health.json).

## Errors

Every error has the same shape:

```json
{ "error": { "code": "empty_input", "message": "Provide a product photo, a description, or both.",
             "request_id": "…", "details": [ … ] } }
```

`details` appears only on `validation_error` (list of `{loc, msg, type}`). Branch on `code`, show `message`.

| HTTP | `code` | When | Suggested UI |
|---|---|---|---|
| 400 | `empty_input` | no image and no text | inline form error |
| 400 | `text_too_long` | text > 1000 chars | inline form error |
| 400 | `invalid_image` | corrupt / not an image | "Please choose another photo" |
| 404 | `unknown_category` | `/confirm` or `/whatif` with a bad id | refresh categories |
| 404 | `demo_no_match` | demo mode and the input isn't a prepared example; `message` lists them | show the list |
| 411 | `length_required` | upload without Content-Length (see proxy note) | developer error |
| 413 | `image_too_large` / `payload_too_large` | file > 8 MB | "Max 8 MB" |
| 415 | `unsupported_image_type` | not JPEG/PNG/WebP | "Use JPEG, PNG or WebP" |
| 422 | `validation_error` | bad field (e.g. `language: "fr"`, override out of range) | developer error |
| 422 | `input_refused` | the AI declined the input | "We can't analyse this input" |
| 429 | `rate_limited` | > 30 analyze/confirm requests per minute from one client IP (`RATE_LIMIT_PER_MINUTE`; behind a dev proxy all browsers share one IP, so the backend should use ~300 while rehearsing); header `Retry-After` (seconds) | "Please wait N s" |
| 502 | `llm_invalid_output`, `llm_error` | the AI answered badly | "Try again" |
| 503 | `llm_unavailable` | AI service down and no prepared example matched | "Try again shortly" |
| 503 | `llm_not_configured` | server has no API key and isn't in demo mode | developer error |
| 500 | `internal_error` | bug; quote `request_id` | generic error |

Examples: [`error_400_empty_input.json`](examples/error_400_empty_input.json),
[`error_413_payload_too_large.json`](examples/error_413_payload_too_large.json),
[`error_415_unsupported_image_type.json`](examples/error_415_unsupported_image_type.json),
[`error_422_validation_error.json`](examples/error_422_validation_error.json),
[`error_503_llm_unavailable.json`](examples/error_503_llm_unavailable.json),
[`error_404_demo_no_match.json`](examples/error_404_demo_no_match.json).

## Arabic / RTL

- Send `language: "ar"` to get the explanation (summary, reasons, concerns, next steps, caveats) in
  Arabic. `report.notes`, `warnings` and error `message`s are English-only: translate errors by `code`,
  or keep these texts in a details area.
- Render `explanation.*` inside `dir="rtl"` when `explanation.language === "ar"`; use `name_ar`
  for product and category names.
- Enum values are English keys; translate them in the UI. Suggested labels:
  `MANUFACTURE` = «صنّعها», `MAYBE` = «ربما», `DONT` = «لا تصنّعها»;
  `growing` = «في نمو», `stable` = «مستقر», `declining` = «في تراجع».
- Numbers are plain JSON numbers (fractions for percentages). Format them in the UI, e.g.
  `new Intl.NumberFormat("ar-JO", { style: "percent", maximumFractionDigits: 1 }).format(0.075)`.
  Money is USD except `machine_cost_range_jod` (JOD).
- The AI explanation may contain Western or Arabic-Indic digits; both are fine to display as-is.

## CORS

Allowed origins come from the server's `CORS_ORIGINS` setting; the default is
`http://localhost:3000,http://localhost:5173` (Next/CRA and Vite dev servers). Ask the backend to add
your deployed origin. The `X-Request-ID` header is exposed to JavaScript.

### `POST /api/budget`

```json
{ "category_id": "tomato_paste", "budget_jod": 100000 }
```

Response ([`budget_partial.json`](examples/budget_partial.json)):
`status` = `covered` (budget ≥ top of the equipment range) | `partial` (≥ bottom) | `short` (below the bottom);
`capex_jod_range` = `capex_usd_range × 0.709`; `gap_jod` = what is still missing to reach the top of the range (0 when covered);
`caption_en` / `caption_ar` = the mandatory equipment-only caption. **Always show the caption**: the range is equipment only
(ex-works listings), excluding shipping, customs, installation, moulds and buildings.
Errors: `404 unknown_category`, `422 capex_unavailable` (category without an equipment range), `422 validation_error`
(`budget_jod` < 0, missing, or extra keys).

### `GET /api/methodology`

[`methodology.json`](examples/methodology.json): `weights`, `thresholds`, `cost_gate`, `min_completeness`, `growth_years`
(numbers come from the scoring code) and `sections.en` / `sections.ar`: a list of `{title, body}` (score, components, cost
gate, data completeness, data sources, and the known limitation that growth uses 2020–2024 with 2020 as a COVID low base).

### Optional response cache (`DB_ENABLED`, branch `db-cache`; additive)

When the server runs with `DB_ENABLED=true` (the default) and **not** in demo mode:

- **`POST /api/analyze` responses get one extra field, `cache`: `"hit"` or `"miss"`.**
  - `hit`: an earlier `complete` or `market_preview` response for the same normalised text (case and spacing ignored), the same image (by SHA-256) and the same `language`, younger than `CACHE_TTL_HOURS` (default 24), was returned without calling the AI. Its `request_id` is new; `timings_ms.normalize` / `explain` are `null`.
  - `needs_confirmation`, `unsupported` and errors are never cached; they always come back as `miss` (errors have no `cache` field).
  - With `DB_ENABLED=false` or in demo mode the field is **absent**: responses are byte-for-byte what they were before.
- **`GET /api/searches/top?limit=10` (`limit` 1–50) is a new endpoint** that exists only while the cache is on (404 otherwise).
  - Response: `{request_id, searches: [{category_id, hs6_guess, name_en, name_ar, count}]}`, most analysed first.
  - It counts `complete` (by `category_id`) and `market_preview` (by `hs6_guess`) results, cache hits included.
  - No personal data: no IP addresses, no request text.

```json
{ "request_id": "…", "searches": [
  { "category_id": "plastic_tableware", "hs6_guess": null, "name_en": "Plastic tableware and kitchenware",
    "name_ar": "أواني ومستلزمات مطبخ بلاستيك", "count": 3 },
  { "category_id": null, "hs6_guess": "690721", "name_en": "Ceramic floor tiles", "name_ar": "بلاط أرضيات سيراميك", "count": 1 } ] }
```
